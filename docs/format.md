# 微软拼音私有词库文件格式（逆向记录）

> 微软没有公开这两个文件的格式。下面是本项目在真实文件上逐字节核对出来的结果，
> 供后来者参考。格式可能随 Windows / 输入法版本变化——如果你手上的文件对不上，
> 欢迎带一段 hexdump 开 issue。
>
> 给作者的信息只保留字段含义与偏移，不含任何人的词库内容。

## 文件位置

```
%APPDATA%\Microsoft\InputMethod\Chs\ChsPinyinUDL.dat       # 词库 / 自学习
%APPDATA%\Microsoft\InputMethod\Chs\ChsPinyinIH.dat        # 输入历史
%APPDATA%\Microsoft\InputMethod\Chs\ChsPinyinUDL_Beta.dat  # Beta 通道版本
```

也可以在「设置 → 时间和语言 → 语言 → 中文(简体) → 选项 → 微软拼音 → 词库和自学习」
里导出 `ChsPinyinUDL.dat`。

## 总体结构

```
+--------------------+-------------------------------+
|  文件头             |  定长 60 字节的记录数组         |
|  UDL: 9216 字节     |  记录 i 的偏移 = 头长 + 60*i    |
|  IH : 5120 字节     |  （第 0 条记录位置为空/保留）    |
+--------------------+-------------------------------+
```

文件头基本是 0，前 24 字节有固定签名，解析时整段跳过即可：

```
UDL: 55 AA 88 81 02 00 60 00 55 AA 55 AA 0C 40 00 00 00 00 00 00 36 87 7D 32
IH : 另有自己的头，长度 5120
```

## UDL 记录（60 字节）

| 偏移 | 长度 | 含义 |
| --- | --- | --- |
| +0 | 4 | 哈希 / 校验，用途不明，可忽略 |
| +4 | 4 | 该词前 3 个音节的「模糊首字母」，ASCII，`\0` 结尾。f/h、n/l、r/l 会被模糊化 |
| +8 | 2 | 常量 `00 04`（目前观察到的值） |
| +10 | 1 | 汉字个数 n（1–12） |
| +11 | 1 | 常量 `0x5A`，可当作记录有效标记 |
| +12 | 2n | 汉字正文，UTF-16LE |
| +12+2n | 2n | n 个 uint16：每个汉字对应的**音节序号** |
| 其余 | — | 补 0 |

例（`作战计划`）：

```
7f 21 d9 30 | 7a 7a 6a 00 | 00 04 | 04 | 5a |
5c 4f 18 62 a1 8b 12 52            # 作战计划 (UTF-16LE)
9c 01 83 01 84 00 7d 00            # 412 387 132 125
```

412/387/132/125 查音节表分别是 `zuo zhan ji hua`。

## IH 记录（60 字节）

| 偏移 | 长度 | 含义 |
| --- | --- | --- |
| +0 | 1 | 汉字个数 n（1–24） |
| +12 | 2n | 汉字正文，UTF-16LE |
| 其余 | — | 补 0 |

IH 里没有音节序号，所以只能还原“词”，不能还原读音。

## 音节表（关键）

音节序号是**一张按字母序排列、共 413 项的普通话音节表**的下标：

```
0=a 1=ai 2=an 3=ang 4=ao 5=ba 6=bai … 405=zi 406=zong 407=zou
408=zu 409=zuan 410=zui 411=zun 412=zuo
```

完整表见 [`src/mspinyin_udl/syllables.py`](../src/mspinyin_udl/syllables.py)，
测试里有若干人工核对过的锚点（如 `395=zhong`、`412=zuo`、`354=xing`）。

因为序号是**跟着词里每个字**存的，多音字不需要猜：`重庆` 存的是 `chong qing`，
`银行` 存的是 `yin hang`，`角色` 存的是 `jue se`。

## 其他性质

* 记录按拼音排序（从头读是 `a…`，结尾是 `zuo…`），所以文件里**没有词频信息**；
  本项目输出的 `weight` 是一个常数（可 `--weight` 指定）。
* 空记录 / 越界记录会被跳过（真实文件末尾通常有几条）。
* 文件可以整体复制回去做恢复；但微软的导入只认自己生成的完整文件，
  所以“转成别的输入法”和“再导回微软”是两件事。
